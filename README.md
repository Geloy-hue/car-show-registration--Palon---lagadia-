# Car Show Registration System

## Project Description
The Car Show Registration System is a web-based application developed for managing vehicle registrations and participant information for a car show event.

## Event Information
- **Event:** Car Show 2027
- **Venue:** Sorsogon City Coliseum
- **Location:** Sorsogon City

## How to Run the Project

### Backend
1. Open the backend solution using Visual Studio.
2. Restore NuGet packages.
3. Run the API project.
4. Open Scalar to view and test the API endpoints.

### Frontend
1. Open a terminal inside the frontend folder.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL displayed in the terminal.
